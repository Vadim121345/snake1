#  Змейка (консольная игра, Windows)

Классическая «Змейка» в терминале: змейка растёт, поглощая еду; при столкновении
с собой или стеной — проигрыш. Управление — стрелками, поле перерисовывается
на месте . Логика полностью отделена от ввода/вывода и покрыта тестами.



## Возможности

- Управление стрелками 
- Еда появляется в случайной свободной клетке
- Счёт растёт при поедании; **уровень** повышается каждые 5 очков
- Скорость **увеличивается** с уровнем 
- Пауза по клавише **P**
- Экран Game Over со счётом и предложением сыграть ещё раз
- Логика покрыта unit-тестами (без терминала и клавиатуры)

---

## Требования

- **Windows** 10/11
- **Python 3.8+**
